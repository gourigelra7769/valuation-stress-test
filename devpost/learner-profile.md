# Learner Profile

## Initial Idea
Valuation Stress-Test Engine: a financial analysis web app for finance students, aspiring equity analysts, and investors. It should show what assumptions could justify a company’s current market valuation and how valuation changes when assumptions shift. The proposed MVP includes a deterministic FCFF reverse DCF solver, valuation stress testing with a tornado chart, and multiple growth/margin paths that yield similar valuations. The learner wants three US-listed non-financial companies with documented inputs and sources, transparent assumptions, valuation date, outputs, and terminal-value contribution. Explicit exclusions: price predictions, buy/sell advice, uncalibrated Monte Carlo, and a large autonomous research agent. Add an AI explainer only after core calculations work and are validated. This is an initial idea, not approved scope.

## Demonstrated Technical and Agent Experience
Second-year CSE student with programming experience in C++, Python, DSA, and basic web development using Next.js, JavaScript/TypeScript, and GitHub. Has installed and started using Codex, but is a beginner with AI coding agents.
Evidence: learner reported this background directly.
